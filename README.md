# Stura3D 다운로드

Stura3D의 공식 설치파일과 자동 업데이트 정보를 제공하는 공개 배포 저장소입니다.

[최신 정식 릴리스](https://github.com/sey-choi/App_Stura3D/releases/latest)에서 운영체제에 맞는 파일을 선택하세요. 정식 릴리스가 표시되지 않으면 배포 준비 중입니다.

- **Windows:** `Stura3D-버전-windows-x64-setup.exe`
- **Mac:** `Stura3D-버전-universal.dmg` — Apple Silicon·Intel 공용
- `latest.json`, `.sig`, `.app.tar.gz`는 앱 자동 업데이트용 파일입니다.
- 파일 무결성은 릴리스의 `SHA256SUMS.txt`로 확인할 수 있습니다.

자동 업데이트를 지원하는 앱은 실행 시 새 버전을 확인합니다. 자동 업데이트 기능이 없는 이전 앱은 지원 버전을 한 번 직접 설치해야 합니다.

이 저장소에는 앱 소스, 사용자 자료, 인증정보를 올리지 않습니다.
